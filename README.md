# Instinct MCP — Gemini CLI / Antigravity extension

Connect Gemini CLI (and Antigravity) to **Instinct MCP** — Fox & Crow's
managed-services (MSP) market intelligence — as a set of read-only tools.

Ask about any managed-services company across the English-speaking market and get
real, sourced answers: firmographics, technology and vendor detection, FCML
operating-maturity scores, reputation, hiring and change signals, revenue
estimates, infrastructure and security posture, and market sizing. All tools are
read-only and return company-level business data (no personal contact info),
metered as prepaid pay-as-you-go credits.

## Install

```bash
gemini extensions install https://github.com/Fox-Crow-Group-INC/instinct-mcp-extension
```

The extension registers the remote MCP server at `https://mcp.mspmcp.com/mcp`.
On first use you'll sign in (OAuth) and it draws from your credit balance.

- Sign up / manage credits: https://mcp.mspmcp.com/
- Docs: https://mcp.mspmcp.com/guide
- Site: https://mspmcp.com
